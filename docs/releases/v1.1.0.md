## v1.1.0 更新内容

- 新增启动更新检查：每次启动仅检查一次 GitHub 最新正式版本，没有新版本或检查失败时不会打扰正常使用。
- 新增独立版本提示窗口，显示当前版本、最新版本、发布日期和完整更新说明，不受主时钟闲置紧凑模式影响。
- 新增 `ghfast.top` 代理更新入口，仅在用户确认后下载安装包。
- 根据 Windows、Debian/Ubuntu、RPM 和 Arch Linux 环境选择对应的 x64 安装包。
- 下载时显示实时进度，并支持关闭提示窗口以取消下载。
- 启动安装程序前校验 GitHub 提供的文件大小和 SHA-256 摘要；校验失败时阻止执行。

## 安装包

- Windows x64：`.exe` 或 `.msi`
- Debian、Ubuntu、Linux Mint 等 amd64 发行版：`.deb` 或 `.dpkg`
- Fedora、openSUSE、RHEL 系 x86_64 发行版：`.rpm`
- Arch Linux / pacman x86_64：`.pkg.tar.zst`

发布附件中的 `SHA256SUMS.txt` 提供所有安装包的 SHA-256 校验值。
