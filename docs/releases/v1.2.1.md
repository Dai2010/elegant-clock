## v1.2.1 更新内容

- 更新提示窗口新增原地址更新按钮，并将它设为默认高亮和默认键盘焦点。
- 保留 `ghfast.top` 代理更新按钮作为网络不畅时的备用入口。
- 原地址与代理下载共用文件大小和 SHA-256 校验流程，校验通过后才启动系统安装程序。
- 设置页面重新划分为窗口行为、时钟外观、颜色、铃声、启动与更新、关于六个模块。
- 设置页面新增手动检查更新入口；发现新版本时打开独立更新提示窗口，已是最新版或检查失败时显示明确状态。
- 背景颜色支持色彩选择器和 `#RRGGBB` 十六进制编码双向同步输入；无效编码不会写入配置。

## Windows 验证

发布流程继续在原生 Windows runner 上同时生成 EXE 和 MSI，并运行打包后的 Elegant Clock，确认独立守护进程能够启动、通信和正常退出后才上传安装包。
